# 大学生该做的 100 件事

一个奶油纸质手账风格的打卡清单网站：100 件大学小事，可以逐件珍藏，也可以加自己的。

在线访问：<https://workbuddy.link/p/gC6b8aycb9SydBacDPKfdr>

## 功能

- **100 件小事分 10 个分类**：校园时光、青春日常、朋友之间、一个人的浪漫、小小远方、关于热爱、勇敢一点、感受世界、留下痕迹、好好告别
- **卡片墙**：按分类分组展示，支持关键词搜索 + 分类筛选 + 状态筛选
- **记录面板**：点卡片即可设置状态（想去做 / 等待发生 / 已经珍藏 / 留给以后）、完成日期、当时的心情、一句话记录
- **拍照记录**：支持直拍和相册选图，自动压缩到 1000px 后上传；独立的「照片墙」页签带灯箱浏览
- **我的大学章节**：Lv.1 → Lv.6 六个章节（0 / 20 / 40 / 60 / 80 / 100 件），含完成度、心情 Top3、关键词云、写给自己的话、最近珍藏时间线
- **添加自己的小事**：工具栏「+ 添加小事」，编号自动接在 100 之后，卡片带「我加的」标记

## 数据存储

页面通过 WorkBuddy 资料库的 Page SDK（`window.__SMART_PAGE__.database`）读写云端数据表，实现跨设备在线存储与双向同步：

- `getSchema` 读取分类 / 心情选项，界面完全由数据表结构驱动
- `query` 分页拉取全部记录
- `updateRecord` 增量保存单条记录
- `addRecord` 新增自己的小事
- `uploadImage` 上传照片，拿到 URL 后写入 `image` 字段

离线时自动降级到 localStorage 缓存 + 内置清单，恢复网络后自动重试对账。

## 本地预览

直接用浏览器打开 `fix2_work/src/大学生该做的100件事.html` 即可。没有 SDK 时页面会走离线兜底模式，展示内置的 100 件小事。

## 技术说明

单文件 HTML，CSS 与 JS 全部内联，不依赖任何外部 CDN，可直接双击打开。所有样式基于 CSS 变量，浅色纸质主题。
